# vn-engine-ps1

Motor en C (PSn00bSDK) para novelas visuales en PlayStation 1. Licencia MIT (ver `LICENSE`). Viene del port de Snoot Game
(`snoot-ps1`, v1.0) y crece con cada juego que se porta: hoy, *I Wani Hug that Gator!*
(`wani-ps1`).

Los datos de cada juego (guion, imágenes, audio) los preparan los ports con el kit
`renpy-port-kit`. Plan y estado: `PLAN.md` y `STATUS.md`.
