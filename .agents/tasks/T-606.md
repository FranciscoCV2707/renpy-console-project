# T-606 — PlayStation 4: Snoot con el backend SDL y los datos del disco de PS1

- **Estado:** assigned
- **Agente:** agy
- **Fase:** 6 (PLAN.md sección 6, D23)
- **Depende de:** T-401, T-405 (hechas)

## Objetivo
Compilar Snoot para PlayStation 4 con el mismo backend `platforms/sdl/` que ya corre en PC (PLAN.md D21), con la toolchain
en Docker fijada por digest, y dejar el paquete listo: `build/ps4/` (eboot.bin y el paquete FPKG `.pkg`). Lee los archivos del disco de PS1 desde `/data/snoot/`.

## Contexto mínimo
- Lee: `PLAN.md` D18, D21, D22; `docs/platform-matrix.md` (fila de PlayStation 4); `platforms/sdl/` completo;
  `docs/platforms/pc.md`; cómo lo resolvieron otras consolas: `platforms/ps2/build.py`, `docs/platforms/psp.md` y
  `docs/platforms/ps2.md` (imagen por digest, `-iquote` para que nuestros `input.h`/`video.h` ganen a los del SDK).
- SDK: OpenOrbis PS4 Toolchain con el SDL2 de sus portlibs. Lee primero `docs/platforms/research/ps4.md` (T-R01):
  propone el `Dockerfile` oficial de OpenOrbis (`DOCKER.md`) o la imagen `xfangfang/pacbrew`; elige una, fíjala por
  digest y cita de dónde sale cada paquete. No inventes nombres de paquetes.
- Pantalla: 1920×1080 (los 320×240 de PS1 ×4 = 1280×960, centrados).
- Datos: `build/ctl/ps1/disc/` (los deja `python -m tools.ctl run --target ps1 --scenario tests/scenarios/snoot-smoke.yaml`).

## Archivos permitidos
- `platforms/ps4/**`, `platforms/sdl/**` solo con `#ifdef __ORBIS__` (o la macro que defina el SDK; cítala) donde la
  consola difiera (pantalla, rutas, entrada), `docs/platforms/ps4.md` (nuevo), `docs/platform-matrix.md` (solo la
  fila de PlayStation 4), `tests/test_ps4_build.py` (nuevo), `reports/T-606.md`

## Archivos prohibidos
- `engine/**`, `platforms/ps1/**`, `platforms/psp/**`, `platforms/ps2/**`, `tools/**`, repos hermanos.
- No descargues emuladores, BIOS, claves ni firmware. Las imágenes Docker de la toolchain sí.

## Pasos sugeridos
1. `platforms/ps4/build.py`: corre la toolchain en Docker con `subprocess.run([...], check=True)` (en Git Bash, la
   ruta montada necesita `MSYS_NO_PATHCONV=1`; desde Python no). Compila `engine/core`, `engine/app`, `engine/modules`,
   `games/snoot` y `platforms/sdl`; `--trace` define `VN_TRACE`. Salida: `build/ps4/` (eboot.bin y el paquete FPKG `.pkg`).
2. Ajustes de la consola en `platforms/sdl` con `#ifdef`, lo mínimo: pantalla, ruta de datos, botones a `BTN_*`.
3. `tests/test_ps4_build.py`: se salta si Docker no está; si está, compila y comprueba que salga el paquete.
4. `docs/platforms/ps4.md`: imagen y digest, cómo compilar, cómo instalar en la consola o el emulador (shadPS4) y qué
   falta para correrlo automático con `tools/ctl` (no lo implementes en esta tarea).
