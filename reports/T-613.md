## APIs externas usadas
- `rpcs3 --help` (build 0.0.43-20410-c365ea76): `--headless`, `--no-gui`, `--installfw <pup>`, `--installpkg
  <pkg>`; firmware 4.93 instalado desde `E:\snoot\ps3 firmware\PS3UPDAT.PUP` con
  `--headless --installfw` (RPCS3.log: "Successfully installed PS3 firmware version 4.93").
- `log/TTY.log` junto al exe: sys_tty_write del juego (verificado: ahí caen los printf del motor).
- `--headless` fuerza renderer Null (RPCS3.log: "The video renderer 'Vulkan' is currently not supported in
  headless mode"); para correr el juego se usa `--no-gui`.
- Bug confirmado en `SDL_psl1ghtaudio.o` (libSDL2.a de la imagen Docker, GCC 13.2.0): formato
  `PSL1GHT_AUD_OpenDevice(%08X.%08X, %s, %d)` cuyos últimos dos args vienen de registros que el llamador de
  SDL2 2.31 no inicializa (firma antigua de `OpenDevice`); en RPCS3 el `%s` vale `0x1` →
  `vfprintf` desreferencia → "Access violation reading location 0x1" (PC 0x10e57c), "Emulation has been
  frozen" a los 0:09. Reproduce igual con PPU Decoder Interpreter.

## Decisiones y supuestos
- El disco PS1 se toma de `build/ctl/ps1/disc` como los adapters PSP/Vita (prerrequisito `ctl run --target ps1`).
- Instaladores headless de RPCS3 terminan con ruido de teardown ("Verification failed (object: 0x0)") y exit
  code no fiable: se comprueba el efecto (`dev_flash/sys`, `EBOOT.BIN`) y no el código de retorno.
- `--installpkg` exige ruta absoluta (con relativa: "PKG file not found!").

## Propuestas de cambio a contratos (si aplica)
- Ninguna al núcleo. Propongo tarea nueva: parchear `SDL_psl1ghtaudio.c` en la imagen Docker (printf con args
  correctos o firma nueva de `OpenDevice`) o compilar SDL2 con el driver dummy; alternativa: opción de build
  para el backend SDL que omita `audio_init` en PS3 (tocaría `engine/app/main.c` o `platforms/ps3/Makefile`).
