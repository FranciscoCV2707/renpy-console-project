  failed (object: 0x0)`); OpenGL igual (`GLTextureCache.h:729`). Con `Force CPU Blit: true` el crash desaparece y el

## Decisiones y supuestos
- La config propia usa OpenGL + `Force CPU Blit` + buffers/strict: es la unica combinacion que evita el crash del
  cache de texturas en este host y la que acompano la unica corrida con flips continuos a ~30 fps.
- No toque `sdl_target.h` ni parchee SDL_PSL1GHT: el crash/cuelgue esta en el pipeline flip/texturas del emulador en
  este host, no en los blits chicos (con CPU blit no hay blits GPU y el cuelgue sigue); y no se parchea el wait del
  flip porque en hardware es necesario (tarea, punto 3).
- El disco de PS1 (`build/ctl/ps1/disc`) se copio del build del repo principal (mismo commit e6f34b3, mismo
  conversor determinista) porque el prerrequisito `ctl run --target ps1` no se habia corrido en este worktree.
