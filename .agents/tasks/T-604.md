# T-604 — Xbox clásica: Snoot con el backend SDL y los datos del disco de PS1

- **Estado:** assigned
- **Agente:** beam
- **Fase:** 6 (PLAN.md sección 6)
- **Depende de:** T-401, T-405 (hechas)

## Objetivo
Compilar Snoot para Xbox clásica con el mismo backend `platforms/sdl/` que ya corre en PC (PLAN.md D21), con la toolchain
en Docker fijada por digest, y dejar el paquete listo: `build/xbox/default.xbe` (y la carpeta para una ISO XISO). Lee los archivos del disco de PS1 desde `D:\data\`.

## Contexto mínimo
- Lee: `PLAN.md` D18, D21, D22; `docs/platform-matrix.md` (fila de Xbox clásica); `platforms/sdl/` completo;
  `docs/platforms/pc.md`; cómo lo resolvieron otras consolas: `platforms/ps2/build.py`, `docs/platforms/psp.md` y
  `docs/platforms/ps2.md` (imagen por digest, `-iquote` para que nuestros `input.h`/`video.h` ganen a los del SDK).
- SDK: nxdk (trae su propio SDL2). Imagen: la imagen Docker oficial de nxdk si existe; si no, un `Dockerfile` en `platforms/xbox/` que lo arme desde su repositorio, fijado a un commit. Fija la imagen por digest (`docker inspect --format "{{index .RepoDigests 0}}"`)
  y cita de dónde sale cada paquete (página oficial o `dkp-pacman -Ss`); no inventes nombres de paquetes.
- Pantalla: 640×480 (los 320×240 de PS1 ×2).
- Datos: `build/ctl/ps1/disc/` (los deja `python -m tools.ctl run --target ps1 --scenario tests/scenarios/snoot-smoke.yaml`).

## Archivos permitidos
- `platforms/xbox/**`, `platforms/sdl/**` solo con `#ifdef NXDK` (o la macro que defina el SDK; cítala) donde la
  consola difiera (pantalla, rutas, entrada), `docs/platforms/xbox.md` (nuevo), `docs/platform-matrix.md` (solo la
  fila de Xbox clásica), `tests/test_xbox_build.py` (nuevo), `reports/T-604.md`

## Archivos prohibidos
- `engine/**`, `platforms/ps1/**`, `platforms/psp/**`, `platforms/ps2/**`, `tools/**`, repos hermanos.
- No descargues emuladores, BIOS, claves ni firmware. Las imágenes Docker de la toolchain sí.

## Pasos sugeridos
1. `platforms/xbox/build.py`: corre la toolchain en Docker con `subprocess.run([...], check=True)` (en Git Bash, la
   ruta montada necesita `MSYS_NO_PATHCONV=1`; desde Python no). Compila `engine/core`, `engine/app`, `engine/modules`,
   `games/snoot` y `platforms/sdl`; `--trace` define `VN_TRACE`. Salida: `build/xbox/default.xbe` (y la carpeta para una ISO XISO).
2. Ajustes de la consola en `platforms/sdl` con `#ifdef`, lo mínimo: pantalla, ruta de datos, botones a `BTN_*`.
3. `tests/test_xbox_build.py`: se salta si Docker no está; si está, compila y comprueba que salga el paquete.
4. `docs/platforms/xbox.md`: imagen y digest, cómo compilar, cómo instalar en la consola o el emulador (xemu (necesita BIOS y disco duro del usuario: no los descargues, solo documenta qué hace falta)) y qué
   falta para correrlo automático con `tools/ctl` (no lo implementes en esta tarea).
