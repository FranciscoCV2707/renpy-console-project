## Objetivo
`python -m tools.ctl run --target ps1 --scenario tests/scenarios/snoot-smoke.yaml` arma el disco de Snoot con el
motor de este repo y el `AUTOTEST.BIN` del escenario, lo corre en PCSX-Redux sin interfaz, guarda la TTY,
extrae la traza y escribe el veredicto con `compare_scenario` y `write_report`. Es la compuerta G2.

## Pasos sugeridos
1. `ps1.py`: `run_scenario(scenario, out_dir) -> Path` (devuelve la ruta de la traza). Arma el disco con
   `snoot.build_disc(REPO, autotest_bin(steps), out_dir / "disc")`; genera el Lua de `emutest.LUA` como en
   `snoot.play`; lanza PCSX-Redux con `-stdout` además de los argumentos de `snoot.play`, con stdout a
   `out_dir / "tty.txt"`; mismo criterio de salida de `snoot.play` (espera `final.txt` + margen, luego
   `taskkill`) y además corta en `scenario.limits.max_seconds`. Escribe `out_dir / "trace.txt"` con solo las
   líneas `T|`.
2. `extract_trace(tty_text) -> str` separado, para probarlo sin emulador.
3. `__main__.py run`: `--scenario` es la ruta del YAML; carga, corre, compara, escribe el reporte e imprime el
   veredicto; código 0 si coincide, 1 si no, 2 si falla el arranque. `--suite` sigue pendiente (mensaje claro).
4. `testlab.toml`: deja solo lo que `ps1.py` lee de verdad (o bórralo si no hace falta nada).
5. Pruebas sin emulador: `extract_trace` con TTY mezclada, y `run` con `run_scenario` falso para cada código de
   salida.
