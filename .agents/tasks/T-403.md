# T-403 — Decodificadores de audio de PS1 (SPU-ADPCM y XA) en C para PC

- **Estado:** assigned
- **Agente:** beam
- **Fase:** 4 (PLAN.md sección 6)
- **Depende de:** —

## Objetivo
`platforms/sdl/psx_audio.c/.h`: decodifica a PCM 16 bits los dos formatos de audio del disco de PS1 de Snoot, para que
el backend SDL (T-401, en paralelo) reproduzca la música y los efectos con los mismos datos (PLAN.md D21).

## Contexto mínimo
- Formato de este juego: `E:\Dev\snoot-ps1\docs\formato-audio.md` (música XA en 16 carriles en `MUSIC.XA`, efectos y
  ambientes `S###.SPU`, índice `AUDIO.BIN`). Archivos reales: `E:\Dev\snoot-ps1\build\data\` (`MUSIC.XA`, `SFX\`).
- Cómo los usa el motor (solo para entender, no lo copies): `platforms/ps1/audio.c`.
- Algoritmo: psx-spx, secciones "SPU ADPCM" (bloques de 16 bytes, 28 muestras, filtros 0-4) y "CDROM XA-ADPCM" (sectores
  de 2336/2352 bytes, 18 grupos de 128 bytes, 4 o 8 bits, 37800/18900 Hz, mono/estéreo). Usa las tablas de filtro de
  psx-spx tal cual y cítalas.

## Archivos permitidos
- `platforms/sdl/psx_audio.c`, `platforms/sdl/psx_audio.h` (nuevos), `tests/core/test_psx_audio.c` (nuevo),
  `tests/test_psx_audio.py` (nuevo), `reports/T-403.md`

## Archivos prohibidos
- El resto de `platforms/sdl/` (lo hace T-401), el motor, repos hermanos, todo lo demás.

## Interfaz
```c
/* Decodifica `blocks` bloques SPU-ADPCM de 16 bytes; hist guarda las dos ultimas muestras entre llamadas */
int psx_spu_decode(const uint8_t *adpcm, int blocks, int16_t *out, int32_t hist[2]);
/* Decodifica un sector XA (los 2304 bytes de datos tras la subcabecera) de un carril; devuelve muestras por canal */
int psx_xa_decode_sector(const uint8_t *data, int stereo, int bits8, int16_t *left, int16_t *right, int32_t hist[4]);
```
C99, `-Wall -Wextra -pedantic -Werror`, sin memoria dinámica, sin nada de SDL (el backend lo llama).
