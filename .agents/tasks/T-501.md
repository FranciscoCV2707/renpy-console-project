# T-501 — Port PSP con el backend SDL y los datos del disco de PS1

- **Estado:** assigned
- **Agente:** kilo
- **Fase:** 5 (PLAN.md sección 6)
- **Depende de:** T-401, T-405 (hechas)

## Objetivo
`EBOOT.PBP` de Snoot para PSP: el mismo backend `platforms/sdl/` compilado con el SDL2 de pspdev (en Docker), que lee
los archivos del disco de PS1 (PLAN.md D21) desde la Memory Stick. Llega al título y a la primera línea en PPSSPP, y
`ctl` le saca la traza.

## Contexto mínimo
- Lee: `PLAN.md` D18, D21, D22; `docs/platforms/psp.md` (imagen Docker por digest, SDL2 2.32.10 con
  `psp-pkg-config`); `platforms/psp/hello/`; `platforms/sdl/` completo y `docs/platforms/pc.md`; `tools/ctl/pc.py`.
- Datos: `build/ctl/ps1/disc/` (los deja `python -m tools.ctl run --target ps1 --scenario tests/scenarios/snoot-smoke.yaml`).
- Emulador: `E:\snoot\ppsspp-1.20.4\PPSSPPWindows64.exe` (no trae versión sin ventana). Averigua con su ayuda
  (`--help`) y la documentación oficial de PPSSPP cómo: arrancar un `EBOOT.PBP` directo, usar una carpeta como Memory
  Stick, cerrar al terminar y guardar en un archivo lo que el juego escribe por stdout/`printf` (la traza). Cita la
  fuente de cada opción en el reporte; no inventes opciones.

## Archivos permitidos
- `platforms/psp/**` (salvo `hello/`), `platforms/sdl/**` solo con `#ifdef __PSP__` donde la PSP difiera (pantalla
  480×272, rutas `ms0:/`, sin `SDL_GameController` si no hace falta), `tools/ctl/psp.py` (nuevo),
  `tools/ctl/__main__.py` (solo agregar el target `psp`), `tests/test_ctl_psp.py` (nuevo), `docs/platforms/psp.md`,
  `reports/T-501.md`

## Archivos prohibidos
- `engine/**`, `platforms/ps1/**`, `tools/agents/**`, repos hermanos. No descargues nada más.

## Pasos sugeridos
1. `platforms/psp/Makefile` (o `build.py` que llame a Docker con `subprocess.run([...], check=True)`): compila
   `engine/core`, `engine/app`, `engine/modules`, `games/snoot` y `platforms/sdl` con `psp-gcc` y el SDL2 de pspdev;
   `--trace` define `VN_TRACE`. Salida: `build/psp/EBOOT.PBP`.
2. Pantalla: los 320×240 de PS1 escalados a 360×272, centrados en 480×272.
3. Archivos: `cd_find`/`VN_DATA_DIR` apuntan a `ms0:/PSP/GAME/SNOOT/DATA/`; `AUTOTEST.BIN` se lee de ahí igual que en PC.
4. `tools/ctl/psp.py`: arma la carpeta de Memory Stick en `build/ctl/psp/ms/` (EBOOT + datos + `AUTOTEST.BIN`), corre
   PPSSPP y extrae las líneas `T|` de su salida.
