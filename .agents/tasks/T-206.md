## Pasos sugeridos
1. `docker pull pspdev/pspdev:latest` y `docker pull ps2dev/ps2dev:latest`; anota la etiqueta y el digest
   (`docker inspect --format "{{index .RepoDigests 0}}"`).
2. Confirma dentro de cada imagen qué compilador trae y si incluye SDL2 (`psp-pkg-config --list-all`,
   `ls /usr/local/ps2dev/...` o lo que corresponda). No adivines rutas: compruébalas.
3. Compila el `hello` de cada plataforma con `docker run --rm -v "${PWD}:/src" -w /src <imagen> ...` y verifica que
   salga el `EBOOT.PBP` (PSP) o el `.elf` (PS2). No subas los binarios (`.gitignore` ya ignora `*.elf`; agrega
   `EBOOT.PBP` a la lista de pendientes del reporte si no está ignorado).
4. En cada doc: imagen con digest, comando exacto de compilación, salida esperada, problemas que encontraste.
